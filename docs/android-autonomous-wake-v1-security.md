## 发现与修复

| 检查项 | 原风险 | 修复 |
| --- | --- | --- |
| Token 输入 | 普通 EditText 会直接绘制密钥 | XML 设置密码类型；程序强制使用全字符即时遮蔽，不闪现最后输入字符。实际保存和认证仍使用原始输入，不将遮蔽符号当成 Token |
| 无障碍 | 原采集器直接读取节点文本，包括密码字段 | Token 字段从普通无障碍树排除；直接查询节点/文本事件也仅返回隐藏信息；自有采集器跳过密码节点和 Token 节点，普通节点仍保留文本与点击信息 |
| 连接页截图 | 截图可能包含连接凭据或输入过程 | 展开连接设置时设置 FLAG_SECURE，并阻止自有截图请求及回调上传；隐藏连接设置/切换到其他页面后解除该窗口保护。其他应用/页面继续使用原截图路径 |
| 调试日志 | 网络响应正文、异常消息可能反射凭据 | HTTP 日志只记录状态码，异常只记录类别；日志统一在写入前脱敏当前 Token 的原文、URL/JSON 编码及常见凭据字段，并在读取时再次脱敏 |
| 历史日志 | 已截断的旧日志不能可靠地反向识别密钥 | 安全更新首次访问调试日志时清理旧诊断文本一次；不清除连接设置、事件队列或其他业务数据 |
| 系统状态保存 | 输入框可能进入 Activity 状态和自动填充流程 | Token 禁用 View 状态保存与自动填充；关闭输入法个性化学习标记，不新增明文显示入口 |

截图保护范围为本应用的连接设置和 Token。没有实现对任意外部应用截图的通用秘密识别；外部页面截图仍按原授权行为工作，不据此宣称图片中所有第三方秘密都会被自动识别。
